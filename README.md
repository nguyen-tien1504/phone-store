# 📱 Phone Store

Dự án **Phone Store** là một ứng dụng web bán điện thoại trực tuyến, bao gồm **frontend** (ReactJS) và **backend** (NodeJS + MongoDB).  
Mục tiêu: xây dựng một cửa hàng trực tuyến với các chức năng quản lý sản phẩm, người dùng và giỏ hàng.

---

## 🚀 Công nghệ sử dụng

- **Frontend**: [ReactJS](https://reactjs.org/) + [Axios](https://axios-http.com/)  
- **Backend**: [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)  
- **Database**: [MongoDB](https://www.mongodb.com/)  
- **Quản lý gói**: npm / yarn  

---

## ✨ Tính năng chính

- 👤 Đăng ký, đăng nhập người dùng  
- 📱 Quản lý sản phẩm (thêm, sửa, xóa, xem danh sách)  
- 🛒 Giỏ hàng và đặt hàng  
- 🔍 Tìm kiếm sản phẩm  
- 🔐 Xác thực và phân quyền (user / admin)  

---

## ⚙️ Cài đặt & chạy dự án

### 1. Clone repo
```bash
git clone https://github.com/nguyen-tien1504/phone-store.git
cd phone-store
```
### 2. Cài đặt Frontend
```bash
cd phone.store.client
npm i
npm run dev
Open [http://localhost:5173/](http://localhost:5173/)
```

### 3. Cài đặt Backend
```bash
cd phone.store.server
npm i
npm run dev
Open [http://localhost:3000/](http://localhost:3000/)
```
